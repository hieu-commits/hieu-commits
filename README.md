## About me

Hi, I'm **Hieu** (`hieu-commits`). I'm building practical skills across software engineering, networks, cybersecurity, DevOps, databases, IoT and cloud fundamentals.

My approach is hands-on: write code, build small labs, verify behavior, document what changed and iterate. I value readable implementations, reproducible experiments and secure-by-design thinking over buzzwords.

**Current learning focus:** C/C++, Python, web fundamentals, AI/ML experiments, network engineering, defensive security, automation, SQL and connected systems.

## Engineering principles

- **Readable:** prefer clear names, small functions and useful documentation.
- **Reproducible:** record setup steps, assumptions, commands and test cases.
- **Observable:** use logs, metrics and packet captures to understand system behavior.
- **Secure-minded:** use least privilege and test only systems I own or am authorized to assess.
- **Evidence over claims:** show code, tests, architecture and results whenever possible.

## Learning roadmap

- [ ] Strengthen C/C++, pointers, memory and data structures.
- [ ] Build Python utilities with validation, tests and useful error handling.
- [ ] Run small AI/ML experiments with baselines and clear evaluation.
- [ ] Document routing, VLAN, firewall and troubleshooting labs.
- [ ] Practice SQL, relational modeling, normalization and query design.
- [ ] Explore containers, CI/CD, infrastructure as code and cloud fundamentals.
- [ ] Build a small MQTT telemetry pipeline and document its security model.
