## 👨‍💻 About Me

I'm an IT enthusiast interested in understanding how
network infrastructure, software and connected devices work.

- 🌐 Networking: TCP/IP, VLAN, routing and switching
- 🔥 Network Infrastructure: MikroTik, firewalls and virtualization
- 🔌 Embedded Systems: C/C++, microcontrollers and ESP32
- 📡 IoT: Sensors, device communication and MQTT
- 🔐 Cybersecurity: Network analysis, system hardening and defense
- 🐧 Systems: Linux, Windows and IT automation
- ⚙️ Automation: Python and PowerShell

I enjoy building practical labs, troubleshooting technical problems,
and documenting what I learn through real projects.
